# SQL — Основы

## Что такое SQL

SQL (Structured Query Language) — структурированный язык запросов для взаимодействия с реляционными базами данных. Позволяет создавать, извлекать, изменять и удалять данные, а также управлять ими.

---

## Нормализация

Нормализация — метод оптимизации структуры базы данных. В нормализованной базе нет повторяющихся данных, её проще изменять и сопровождать.

**Ключевые принципы:**
- Не хранить составные данные в одной колонке
- У каждой записи должен быть первичный уникальный ключ
- Не хранить дубликаты

Для нормализации создают дополнительные таблицы и связывают их ключами — столбцами без повторяющихся значений.

### Нормальные формы

**1NF (Первая нормальная форма):**
- Все значения атомарны (не списки, не JSON-массивы)
- Нет повторяющихся групп столбцов (`phone1`, `phone2`, `phone3`)
- Есть первичный ключ

```
❌  orders: id | products       | prices
           1  | "book, pen"   | "10, 2"

✅  order_items: order_id | product | price
                1        | book    | 10
                1        | pen     | 2
```

**2NF (Вторая нормальная форма):**
- Выполнена 1NF
- Нет частичных зависимостей: каждый не-ключевой столбец зависит от **всего** первичного ключа, а не от его части

```
❌  order_items: order_id | product_id | product_name | quantity
    product_name зависит только от product_id, а не от (order_id, product_id)

✅  order_items: order_id | product_id | quantity
    products:    product_id | product_name
```

**3NF (Третья нормальная форма):**
- Выполнена 2NF
- Нет транзитивных зависимостей: не-ключевые столбцы не зависят друг от друга

```
❌  employees: id | department_id | department_name
    department_name зависит от department_id, а не от id

✅  employees:   id | department_id
    departments: department_id | department_name
```

**Практика:** в большинстве случаев достаточно 3NF. Денормализация (намеренное отступление от нормальных форм) применяется для производительности — например, хранить `total_amount` в таблице заказов, чтобы не считать каждый раз.

## Подмножества SQL

| Подмножество | Полное название | Назначение | Команды |
|---|---|---|---|
| DDL | Data Definition Language | Управление структурой | CREATE, ALTER, DROP |
| DML | Data Manipulation Language | Управление данными | SELECT, INSERT, UPDATE, DELETE |
| DCL | Data Control Language | Управление доступом | GRANT, REVOKE |

---

## DELETE vs TRUNCATE

| | DELETE | TRUNCATE |
|---|---|---|
| Подмножество | DML | DDL |
| Условие WHERE | Да | Нет |
| Логи транзакций | Да | Нет |
| Откат (ROLLBACK) | Возможен | Невозможен |
| Скорость | Медленнее | Быстрее |

```sql
-- DELETE — удаляет записи по условию, можно откатить
DELETE FROM orders WHERE status = 'cancelled';

-- TRUNCATE — пересоздаёт таблицу целиком, откат невозможен
TRUNCATE TABLE temp_log;
```

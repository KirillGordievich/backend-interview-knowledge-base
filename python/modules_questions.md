# Python — Модули и импорты: Вопросы

> Теория: [modules.md](modules.md)

---

**Q: Чем отличается модуль от пакета?**

- **Модуль** — один `.py` файл
- **Пакет** — директория с `__init__.py` (или без — namespace package). Может содержать подмодули и подпакеты.

---

**Q: Как работает система импортов в Python?**

1. Проверяет `sys.modules` (кэш загруженных модулей)
2. Если нет — ищет модуль по путям из `sys.path`
3. Находит → компилирует в байткод (.pyc) → выполняет код модуля → кэширует в `sys.modules`

Модуль выполняется **один раз** при первом импорте. Повторный `import` возвращает объект из кэша.

---

**Q: Что такое `sys.path` и как Python ищет модули?**

`sys.path` — список директорий, где Python ищет модули. Порядок: директория скрипта → `PYTHONPATH` → стандартная библиотека → site-packages. Можно модифицировать: `sys.path.append('/my/path')`.

---

**Q: В чём разница `import module` и `from module import name`?**

- `import module` — импортирует модуль целиком, обращение через `module.name`
- `from module import name` — импортирует конкретное имя в текущий namespace

```python
import os
os.path.join(...)

from os.path import join
join(...)
```

---

**Q: Что делает `__init__.py`?**

Превращает директорию в пакет. Выполняется при импорте пакета. Может:
- Быть пустым
- Определять `__all__` (что экспортируется при `from package import *`)
- Содержать инициализационный код
- Реэкспортировать из подмодулей

---

**Q: Что такое `__all__`?**

Список имён, которые экспортируются при `from module import *`. Если не определён — экспортируются все имена без подчёркивания.

```python
# mymodule.py
__all__ = ['public_func', 'PublicClass']

def public_func(): ...
def _private_func(): ...  # не попадёт в import *
```

---

**Q: Что такое circular import и как его избежать?**

Ситуация когда модуль A импортирует B, а B импортирует A. Решения:
- Перенести общий код в третий модуль
- Использовать lazy import (import внутри функции)
- Пересмотреть архитектуру

---

**Q: Что такое `importlib.reload()` и когда он нужен?**

Перезагружает уже импортированный модуль — повторно выполняет его код. Нужен в REPL/IPython для обновления кода без перезапуска. Не обновляет ссылки в других модулях, которые уже импортировали старую версию.

---

**Q: Что такое `if __name__ == '__main__'`?**

`__name__` равен `'__main__'` когда скрипт запущен напрямую, и имени модуля когда импортирован. Позволяет отделить код, который выполняется только при прямом запуске:

```python
def main():
    print('Running')

if __name__ == '__main__':
    main()
```

---

**Q: Что такое namespace package?**

Пакет без `__init__.py` (Python 3.3+). Позволяет разным директориям вносить модули в один пакет (полезно для плагинов и распределённых пакетов).

---

**Q: Что такое относительный импорт?**

Импорт относительно текущего пакета:

```python
from . import sibling       # из того же пакета
from .. import parent_mod   # из родительского пакета
from .utils import helper   # из подмодуля
```

Работает только внутри пакетов. В скрипте, запущенном напрямую — не работает.

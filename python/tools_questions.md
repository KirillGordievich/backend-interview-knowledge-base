# Python — Инструменты разработки: Вопросы

> Теория: [tools.md](tools.md)

---

**Q: Что такое линтер и зачем он нужен?**

Линтер — программа для статического анализа кода. Находит нарушения стиля, потенциальные ошибки и проблемы без запуска кода. Нужен для: единого стандарта в команде, раннего обнаружения ошибок, автоматизации в CI/CD.

---

**Q: Чем ruff отличается от flake8 и pylint?**

- **ruff** — написан на Rust, в 100x быстрее flake8. Линтер + форматтер в одном инструменте
- **flake8** — PEP8 + базовые ошибки, богатая экосистема плагинов
- **pylint** — глубокий анализ с множеством правил, самый медленный

---

**Q: Чем линтер отличается от форматтера?**

- **Линтер** (ruff check, flake8) — находит ошибки и проблемы, может не всё автоматически исправить
- **Форматтер** (ruff format, black) — автоматически приводит код к единому стилю (отступы, кавычки, длина строк)

---

**Q: Что такое black и какая его философия?**

Бескомпромиссный форматтер — почти не имеет настроек ("opinionated"). Единый стиль для всех проектов. Устраняет споры о стиле кода в команде.

---

**Q: Что такое mypy / Pyright?**

Статические проверщики типов. Анализируют type hints и находят ошибки типов без запуска кода. Pyright (от Microsoft) — быстрее, используется в Pylance для VSCode. mypy — оригинальный, `mypy --strict` для строгого режима.

---

**Q: Poetry vs pip — в чём преимущества Poetry?**

- Единый `pyproject.toml` вместо `requirements.txt` + `setup.py`
- `poetry.lock` — детерминированные зависимости (точные версии)
- Автоматическое управление виртуальным окружением
- Разделение dev/prod зависимостей (`--group dev`)
- Публикация пакетов

---

**Q: Что такое uv и чем лучше pip/Poetry?**

Современный менеджер пакетов на Rust. Преимущества: значительно быстрее pip, совместим с `requirements.txt`, глобальный кэш пакетов, не требует отдельного Python для работы. Замена pip + venv + pip-tools.

---

**Q: Что такое lock-файл и зачем его коммитить?**

Lock-файл (`poetry.lock`, `uv.lock`) фиксирует точные версии всех зависимостей (включая транзитивные). Гарантирует что у всех разработчиков и в CI одинаковое окружение. Без lock-файла `requests>=2.0` может установить разные версии в разное время.

---

**Q: Что такое pre-commit и зачем нужен?**

Фреймворк для git-хуков. Запускает проверки (линтеры, форматтеры, type checkers) автоматически перед каждым коммитом. Предотвращает попадание некачественного кода в репозиторий.

```yaml
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/astral-sh/ruff-pre-commit
    hooks:
      - id: ruff
      - id: ruff-format
```

---

**Q: Что такое `pyproject.toml`?**

Единый конфигурационный файл проекта (PEP 518, 621). Содержит: метаданные проекта, зависимости, настройки инструментов (ruff, mypy, pytest). Замена `setup.py` + `setup.cfg` + отдельных конфигов.

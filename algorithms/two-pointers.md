# Два указателя (Two Pointers)

Идея: два указателя двигаются по массиву — обычно навстречу друг другу.

```
L →             ← R
[1 2 3 4 5 6 7]
```

## Когда применять

- Массив отсортирован
- Нужно найти пару
- Нужно что-то сделать с концами массива
- Нужно удалить/сжать элементы
- Нужно проверить палиндром

**Триггер:** «У меня есть две стороны/две позиции, которые можно двигать навстречу друг другу» → Two Pointers.

## Пример: проверка палиндрома

```python
left = 0
right = len(s) - 1

while left < right:
    if s[left] != s[right]:
        return False

    left += 1
    right -= 1

return True
```

Двигаем указатели от краёв к центру. Если символы на обоих концах совпадают — продолжаем. Если нет — не палиндром.

**Сложность:** `O(n)` по времени, `O(1)` по памяти.

# Сортировка как приём решения (Sorting)

Очень недооценённый паттерн. Иногда задача выглядит сложной, но после `sort()` становится простой.

## Когда применять

- Порядок значений важен, а исходный порядок — нет
- Нужно найти ближайшие/соседние элементы
- Задача упрощается, если данные упорядочены
- Комбинируется с другими паттернами (Two Pointers, Binary Search)

**Триггер:** «Мне важен порядок значений, а не исходный порядок» → попробовать сортировку.

## Пример: минимальное расстояние между двумя числами

```python
arr.sort()

answer = float('inf')
for i in range(1, len(arr)):
    answer = min(answer, arr[i] - arr[i - 1])
```

После сортировки минимальное расстояние обязательно между соседними элементами — не нужно проверять все пары.

**Без сортировки:** `O(n²)` — перебор всех пар.
**С сортировкой:** `O(n log n)` — сортировка + один проход.

# Стек (Stack)

Последний вошёл — первый вышел (LIFO).

```
push
 ↓
[3]
[2]
[1]
 ↑
pop
```

## Когда применять

Классические признаки:

- Скобки
- Вложенность
- Отмена предыдущего действия
- «Ближайший больший/меньший элемент»
- Выражения (вычисление, парсинг)
- Нужно вернуться к предыдущему состоянию

**Триггер:** «Мне нужно помнить последние открытые/незакрытые вещи» → Stack.

## Пример: проверка правильности скобок

```
([{}]) → true
([)]   → false
```

```python
stack = []
pairs = {')': '(', ']': '[', '}': '{'}

for c in s:
    if c in "([{":
        stack.append(c)
    else:
        if not stack or stack.pop() != pairs[c]:
            return False

return len(stack) == 0
```

Открывающие скобки кладём в стек. Встретили закрывающую — достаём из стека и проверяем, что она соответствует. Если стек пуст в конце — скобки валидны.

**Сложность:** `O(n)` по времени, `O(n)` по памяти в худшем случае.

# Скользящее окно (Sliding Window)

Родственник Two Pointers. Но здесь мы держим **непрерывный кусок** массива или строки:

```
        window
       ↓↓↓↓↓
[1 2 3 4 5 6 7]
  L       R
```

## Когда применять

Если видишь:

- подмассив / подстрока
- «самая длинная» / «самая короткая»
- «не более K»
- «содержит все X»
- «максимальная сумма последовательных элементов»

**Триггер:** «Нужен оптимальный непрерывный кусок» → Sliding Window.

## Пример: самая длинная подстрока без повторяющихся символов

```python
left = 0
seen = set()
answer = 0

for right in range(len(s)):
    while s[right] in seen:
        seen.remove(s[left])
        left += 1

    seen.add(s[right])
    answer = max(answer, right - left + 1)
```

Правый указатель расширяет окно. Если встретили повтор — сдвигаем левый, пока повтор не уйдёт. На каждом шаге фиксируем размер окна.

**Сложность:** `O(n)` — каждый элемент добавляется и удаляется из `seen` максимум один раз.

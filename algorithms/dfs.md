# Обход в глубину (DFS)

Идём как можно глубже, потом возвращаемся.

```
A
├── B
│   ├── D
│   └── E
└── C

DFS: A → B → D → E → C
```

## Когда применять

- Найти все компоненты связности в графе
- Посчитать острова в матрице
- Обойти дерево (preorder, inorder, postorder)
- Проверить, существует ли путь между вершинами
- Задачи на рекурсивные структуры (вложенные скобки, деревья)

**Триггер:** «Мне нужно посетить всю связанную область» → DFS (или BFS).

## Пример: количество островов в матрице

```
11000
11000
00100
00011

Ответ: 3 острова
```

Увидел `1` → запускаешь DFS → помечаешь весь остров как посещённый.

```python
def num_islands(grid):
    n, m = len(grid), len(grid[0])
    count = 0

    def dfs(r, c):
        if r < 0 or r >= n or c < 0 or c >= m or grid[r][c] == '0':
            return
        grid[r][c] = '0'  # помечаем как посещённую
        dfs(r + 1, c)
        dfs(r - 1, c)
        dfs(r, c + 1)
        dfs(r, c - 1)

    for i in range(n):
        for j in range(m):
            if grid[i][j] == '1':
                count += 1
                dfs(i, j)

    return count
```

**DFS vs BFS:** оба обходят граф полностью, но DFS идёт вглубь (стек/рекурсия), BFS — по уровням (очередь). Для кратчайшего пути — BFS. Для обхода всей области — оба подходят.

**Сложность:** `O(V + E)` — каждую вершину и ребро посещаем один раз.

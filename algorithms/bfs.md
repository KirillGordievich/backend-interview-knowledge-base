# Обход в ширину (BFS)

Главный инструмент — **очередь**.

```
        A
      /   \
     B     C
    / \
   D   E

Порядок: A → B → C → D → E
```

BFS обходит граф **по уровням** — сначала все соседи, потом соседи соседей.

## Когда применять

- Кратчайший путь в графе/матрице/лабиринте, где все переходы стоят одинаково
- «За сколько ходов можно добраться из A в B?»
- Распространение чего-то по уровням (например, «гниение апельсинов» — сколько минут пока сгниют все)

**Триггер:** «Минимальное количество шагов от A до B, каждый переход стоит одинаково» → BFS.

## Пример: минимальное количество шагов в матрице

За сколько ходов можно добраться из `(0, 0)` в `(n-1, m-1)`?

```python
from collections import deque

def min_steps(grid):
    n, m = len(grid), len(grid[0])
    queue = deque([(0, 0, 0)])  # (row, col, steps)
    visited = {(0, 0)}

    while queue:
        r, c, steps = queue.popleft()

        if r == n - 1 and c == m - 1:
            return steps

        for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
            nr, nc = r + dr, c + dc
            if 0 <= nr < n and 0 <= nc < m and (nr, nc) not in visited and grid[nr][nc] == 1:
                visited.add((nr, nc))
                queue.append((nr, nc, steps + 1))

    return -1  # путь не найден
```

**Почему BFS гарантирует кратчайший путь:** он обрабатывает все вершины на расстоянии `k` до того, как начнёт обрабатывать вершины на расстоянии `k+1`.

**Сложность:** `O(V + E)` — каждую вершину и ребро посещаем один раз.

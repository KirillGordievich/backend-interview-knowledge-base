# Префиксные суммы (Prefix Sum)

Очень полезный и очень простой паттерн.

Идея: предпосчитать массив накопленных сумм, чтобы потом мгновенно получать сумму любого диапазона.

```
arr    = [2, 4, 1, 5, 3]
prefix = [0, 2, 6, 7, 12, 15]
```

Сумма `arr[1:4]` = `prefix[4] - prefix[1]` = `12 - 2` = `10`.

## Когда применять

- Много запросов «какая сумма элементов от L до R?»
- Вместо `O(n)` на каждый запрос получаем `O(1)`
- Есть также 2D Prefix Sum для матриц

**Триггер:** «Мне много раз нужно получать сумму непрерывного диапазона» → Prefix Sum.

## Пример: построение и использование

```python
# Построение prefix sum
def build_prefix(arr):
    prefix = [0] * (len(arr) + 1)
    for i in range(len(arr)):
        prefix[i + 1] = prefix[i] + arr[i]
    return prefix

# Запрос суммы от L до R (включительно)
def range_sum(prefix, l, r):
    return prefix[r + 1] - prefix[l]
```

```python
arr = [2, 4, 1, 5, 3]
prefix = build_prefix(arr)  # [0, 2, 6, 7, 12, 15]

range_sum(prefix, 1, 3)  # 4 + 1 + 5 = 10
range_sum(prefix, 0, 4)  # 2 + 4 + 1 + 5 + 3 = 15
```

**Сложность:** `O(n)` на построение, `O(1)` на каждый запрос.

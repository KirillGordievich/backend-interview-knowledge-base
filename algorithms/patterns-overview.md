# Паттерны решения алгоритмических задач

Карта для быстрого выбора подхода на интервью.

```
Нужно быстро искать / считать частоту?
        ↓
    HashMap / Set

Есть непрерывный кусок (подмассив/подстрока)?
        ↓
   Sliding Window

Есть две границы / отсортированный массив?
        ↓
   Two Pointers

Есть отсортированный массив
или монотонный ответ?
        ↓
   Binary Search

Есть вложенность / «последний первым»?
        ↓
      Stack

Есть граф / матрица?
        ↓
    DFS / BFS

Нужно минимальное число шагов?
        ↓
       BFS

Нужно оптимальное значение
из предыдущих состояний?
        ↓
       DP

Много запросов суммы диапазона?
        ↓
   Prefix Sum

Нужен постоянно min/max?
        ↓
      Heap

Можно сделать локально лучший
выбор и доказать его?
        ↓
     Greedy

Порядок элементов не важен?
        ↓
     Sorting
```

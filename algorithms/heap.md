# Куча / очередь с приоритетом (Heap)

Когда постоянно нужен минимальный или максимальный элемент, но остальные элементы тоже должны оставаться доступными.

```python
import heapq

heap = []
heapq.heappush(heap, x)     # добавить элемент
x = heapq.heappop(heap)     # достать минимальный
```

В Python `heapq` — это **min-heap** (минимальный элемент сверху). Для max-heap — класть с минусом: `heappush(heap, -x)`.

## Когда применять

- K самых больших/маленьких элементов
- Планирование задач
- Очередь по приоритету
- Merge нескольких отсортированных массивов
- Алгоритмы на графах (Dijkstra)

**Триггер:** «Мне постоянно нужен следующий самый маленький/большой элемент» → Heap.

## Пример: K-й наибольший элемент

```python
import heapq

def kth_largest(nums, k):
    heap = []
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:
            heapq.heappop(heap)  # выкидываем минимальный
    return heap[0]  # в куче остались K самых больших, вершина — наименьший из них
```

Держим min-heap размера K. После прохода по всем элементам в куче остаются K самых больших, а вершина кучи — K-й по величине.

**Сложность:** `O(n log k)` — каждый `push`/`pop` стоит `O(log k)`.

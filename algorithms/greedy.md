# Жадный алгоритм (Greedy)

На каждом шаге берём лучшее решение **прямо сейчас**, не заглядывая вперёд.

## Когда применять

Если локально лучший выбор можно **доказать** как безопасный.

Типичные задачи:

- Выбор непересекающихся интервалов (расписания, бронирования)
- Минимальное количество ресурсов для покрытия задач
- Выбор максимального количества объектов с ограничениями
- Некоторые задачи на монеты и стоимость (но не все — с монетами легко ошибиться)

**Триггер:** «Если я сейчас возьму самый выгодный вариант, это не испортит оптимальный ответ» → подумать про Greedy.

> Но здесь особенно важно доказательство, потому что жадный подход очень легко применить неправильно.

## Пример: максимум непересекающихся интервалов

Есть набор интервалов, выбрать максимум непересекающихся.

```
[1---3]
    [3--5]
       [5----8]
```

Сортируем по правой границе и каждый раз берём тот, который заканчивается раньше:

```python
def max_non_overlapping(intervals):
    intervals.sort(key=lambda x: x[1])  # сортировка по концу
    count = 0
    last_end = float('-inf')

    for start, end in intervals:
        if start >= last_end:
            count += 1
            last_end = end

    return count
```

**Почему работает:** выбирая интервал с самым ранним концом, мы оставляем максимум места для следующих интервалов.

**Сложность:** `O(n log n)` из-за сортировки.

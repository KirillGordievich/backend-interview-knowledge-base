# Когда использовать Hash Map / Set

Идея простая: хранить то, что уже встречалось, чтобы за `O(1)` проверять наличие или считать частоту.

## Когда применять

Если в условии есть:

- «найти повтор»
- «есть ли такой элемент»
- «сколько раз встречается»
- «найти пару»
- «первый уникальный»
- «два элемента с нужной суммой»

**Триггер:** «Мне нужно быстро узнавать, встречался ли уже X?» → `set` / `dict`.

## Пример: два числа с нужной суммой

Найти два числа, сумма которых равна `target`.

Наивный подход — перебор всех пар `O(n²)`. С хэш-таблицей — `O(n)`:

```python
seen = set()

for x in nums:
    if target - x in seen:
        return True
    seen.add(x)
```

Логика: для каждого числа `x` проверяем, видели ли мы уже `target - x`. Если да — пара найдена. Если нет — запоминаем `x` и идём дальше.

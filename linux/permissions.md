# Linux — Права доступа

## Формат прав

```
-rwxr-xr--  1 user group 4096 Jan 1 file.txt
│├──┤├──┤├──┤
│ │   │   └── others (все остальные): r-- = чтение
│ │   └────── group (группа):        r-x = чтение + выполнение
│ └────────── owner (владелец):      rwx = чтение + запись + выполнение
└──────────── тип: - (файл), d (директория), l (симлинк)
```

**Символы прав:**
- `r` (read, 4) — читать файл / просматривать содержимое директории
- `w` (write, 2) — изменять файл / создавать/удалять файлы в директории
- `x` (execute, 1) — выполнять файл / переходить в директорию (`cd`)

---

## chmod

```bash
# Символьный синтаксис
chmod u+x script.sh      # добавить execute владельцу
chmod g-w file.txt       # убрать write у группы
chmod o=r file.txt       # установить только read для остальных
chmod a+r file.txt       # добавить read всем (a = all)

# Числовой синтаксис (octal)
chmod 755 script.sh      # rwxr-xr-x
chmod 644 file.txt       # rw-r--r--
chmod 600 id_rsa         # rw------- (приватный ключ)
chmod 777 file.txt       # rwxrwxrwx (опасно)
```

**Как читать числовой формат:**

```
755 = 7  5  5
      │  │  └── others: 4+1 = r-x
      │  └───── group:  4+1 = r-x
      └──────── owner:  4+2+1 = rwx

Биты: r=4, w=2, x=1
7 = 4+2+1 = rwx
6 = 4+2   = rw-
5 = 4+1   = r-x
4 = 4     = r--
0 =       = ---
```

**Типичные значения:**
- `755` — скрипты, исполняемые файлы, директории с публичным доступом
- `644` — обычные файлы (конфиги, тексты)
- `600` — приватные файлы (SSH-ключи, секреты)
- `700` — директории только для владельца

## chown

```bash
chown user file.txt           # изменить владельца
chown user:group file.txt     # изменить владельца и группу
chown -R user:group dir/      # рекурсивно
```

## Специальные биты

### setuid (SUID) — бит s у владельца

Файл выполняется с правами **владельца файла**, а не запускающего пользователя.

```bash
chmod u+s /usr/bin/passwd    # setuid
# или числом: 4755

ls -la /usr/bin/passwd
# -rwsr-xr-x root root /usr/bin/passwd
#    ^--- s вместо x
```

`passwd` принадлежит root, но обычный пользователь может его запустить — файл выполняется от root.

### setgid (SGID) — бит s у группы

На файле: выполняется с правами **группы файла**.
На директории: новые файлы наследуют группу директории (а не группу создателя).

```bash
chmod g+s /shared/dir/       # setgid на директорию
# или числом: 2755
```

### Sticky bit — бит t у others

На директории: файл может удалить только его **владелец** (или root), даже если у других есть права записи в директорию.

```bash
ls -la /tmp
# drwxrwxrwt  root root /tmp
#          ^--- t (sticky bit)
```

`/tmp` доступна всем для записи, но удалить чужой файл нельзя.

```bash
chmod +t /shared/          # добавить sticky bit
# или числом: 1777
```

### Таблица специальных битов

| Бит | Число | На файле | На директории |
|---|---|---|---|
| setuid | 4xxx | Выполняется от имени владельца | Не используется |
| setgid | 2xxx | Выполняется от имени группы | Новые файлы наследуют группу |
| sticky | 1xxx | Не используется | Удалять могут только владельцы файлов |
